# 운보다 실사 사진 21장 공급 및 권리 검증 안내

## 현재 공급 조건
- 매일 생활 글·사진 슬롯 7개: KST 01 / 04 / 10 / 13 / 16 / 19 / 22시.
- 미리 확보하는 기간은 향후 3일 = 서로 다른 실사 사진 21장. 하루마다 7장의 새 원본이 보충되어야 한다.
- 사진을 90일 재사용하지 않으려면 하루 7장 기준 90일간 **630장 이상**의 서로 다른 사진과 개별 권리 기록이 필요하다. 30일 기준 210장이다.
- 현재 staging bank는 사진 0건이며, 별도의 사진 공급 계약·외부 사진 API 허가·서비스 키 연동이 증빙되지 않았다. 이 문서가 공급 계약 체결이나 사진 확보 자체를 의미하지는 않는다.

## 정식 공급원 후보 선정 순서
1. 운보다가 직접 촬영하고 소유권·초상권을 확인할 수 있는 원본 사진.
2. 실사 촬영 업체가 계약서로 상업 SNS 사용과 자동 품질 검사, 재가공·호스팅을 명확하게 허락한 사진.
3. 상업적 이용 조건을 따로 계약한 사진 서비스/API. 계약서에서 허가된 수집 빈도·저장 방식·재배포·AI 이미지 검수 조건을 확인해야 한다.
- Pexels의 별도 승인 없는 대량·체계적 복사, Unsplash API의 비자동화 및 직접 이미지 URL 사용 조건을 우회하지 않는다. 공개 검색 결과 URL만 가지고 계약 완료라고 간주하지 않는다.

## 공급자에게 전달할 촬영 조건
- 최종 인수 파일: 실제 촬영된 고유한 컬러 JPEG, 1080 × 1350px (4:5), 장당 4.9MB 미만; AI 생성 이미지·일러스트·텍스트 카드 불가.
- 과도한 포토샵 합성이나 식별 가능한 얼굴·상표·모니터 화면·은행/카드 정보·영수증 개인정보가 있는 사진은 제외하거나 개별 권리 검토.
- 실생활의 분명한 장면을 촬영한다: 수첩/책상, 침실/조명, 직장 업무, 장보기/상품, 대화 또는 휴대폰, 식탁/주방, 체크리스트/달력.
- 사람을 알아볼 수 있는 사진은 촬영자의 저작권만으로 충분하지 않으며 해당 인물의 상업 활용 동의서를 추가 확보한다.
- 사진마다 촬영자(권리자), 상업 사용 허용, 게시/호스팅/자동 검수 허용, 기간, 출처 표기 조건, 제3자 권리, 계약서 서명 사실을 증빙한다.
- 공급자가 권리를 철회했거나 계약 사용기간이 만료된 사진은 재사용·신규 SNS 예약 대상에서 제외한다.

## 기술 검수와 등록
1. main에서 `scripts/social/photo-supplier-21pack.py --date YYYY-MM-DD` 실행해 3일·21슬롯의 장면 요구 JSON을 받는다. 또는 GitHub Actions `UNBODA real-photo supplier 21-slot brief (NO MEDIA INTAKE, NO SNS)`의 보존기간 3일 artifact를 사용한다.
2. 사용자·계약자의 비공개 컴퓨터에 21장 JPG와 서명된 권리 증빙 PDF/JSON을 보관하고, 공개 GitHub·일반 채팅·SNS에 계약 원본을 업로드하지 않는다.
3. 각 사진의 비공개 JSON manifest를 만들어 `intake-private-licensed-photo.py --manifest <private-path>`로 로컬 확인한다. 공급자별 서명을 사람 또는 독립 승인 절차로 확인한다.
4. 21개 자료가 모두 준비되면 `photo-supplier-21pack.py --date YYYY-MM-DD --validate-private-pack <private-index>`에서 실제 해시·증빙 유무·21개 날짜/시각·장면·유사 이미지를 검증한다. 통과해도 법적 승인이나 이중 AI 이미지 검수 통과를 뜻하지 않는다.
5. 실제 권리 검토 뒤 보호된 환경에서만 `intake-private-licensed-photo.py --stage`를 개별 실행할 수 있다. 오동작이나 타임아웃 후 자동 재시도를 금지한다. 등록 상태는 무조건 PENDING이다.
6. 별도의 CLIP·BLIP 실제 화소 검수와 관리자의 사용권 판단, 90일 Metricool 전체 이력, 날짜별 사진 릴리스, Metricool 1회 안전 예약, PUBLISHED+정확한 publicUrl 확인이 모두 끝나기 전에는 SNS 게시하지 않는다.

## 현재 차단된 것과 다음 대기조건
- 실제 사진이 들어오지 않았으므로 21/21 공급 성공, SNS 공개, 일일 18/18, 무기한 자동화 완료를 선언할 수 없다.
- GitHub Actions staging용 `UNBODA_STAGING_SERVICE_ROLE_KEY`는 비공개 보호설정에만 둔다. 사진 권리 계약도 공개 저장소에 포함시키지 않는다.
- 월간 Metricool 600건 제한과 기존 홍보·띠운세·영상 예약의 독립 경로는 변경하지 않는다.
