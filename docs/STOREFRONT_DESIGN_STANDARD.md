# 운보다 상품 화면 표준

2026-11-26 승인된 재물운 상품 목록과 상세 디자인을 기준으로 한다.

- 4:3 표지, 큰 주제 제목, 짧은 질문, 주제별 색, 운보다 이름.
- 목록 오른쪽 쉬운 상품명, 질문, 짧은 설명, 실제 가격. 상태·후기는 기존 데이터에 기반해 그림 바깥에 둔다.
- 같은 상품의 상세에도 동일한 표지를 보여준다. 선생님과 기존 상세 구성·구매 경로 유지.
- 재물운 10종의 승인된 생성 이미지와 신년운세 전용 연도별 이미지는 유지한다.
- 나머지 54종은 기존 확보 사진·기간운 그림을 재사용하여 HTML 표지로 구성한다. 새 AI 실사 이미지 파일을 생성한 것은 아니다. 가족 궁합 3종은 기존 가족 사진을 공유하되 제목과 질문을 구분한다. 가족 묶음은 별도 판매 상품이 아니다.
- 새 상품별 그림을 추가할 때 실제 파일, ID, 제목 가독성 및 목록·상세 일치 여부를 검증한다.
- 기존 상품 ID, 이름의 내부 저장값, 가격, 프로필, 추천 순위, 구매 상태, 결제·환불, 리포트 생성 및 열람, 상담, 무료 분석, 선생님 이미지를 바꾸지 않는다.
- 자동 검사·미리보기 배포 이후 운영 배포. 실제 PC/모바일 로그인 화면 검증은 별도 수행한다.
