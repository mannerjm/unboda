## 완료 판정 금지 사항

이 문서를 기록한 시점에 첫 새 사주 영상 4편 제작의 1차 품질검사 결과는
00/08 편 음성·움직임에서 실패, 12 편 1차 기술검사 성공, 20 편 QA 진행 중이었고,
이를 해결하기 위한 렌더러 모션·대본 자연어 수정이 소스 브랜치에 반영되어
새 운영 빌드 **GitHub run 40672350085**에서 전체 4편 재검증이 진행 중임.
**4편 전체 PASS_TECHNICAL_ONLY 및 실제 새 Release 존재 확인 전에는 완성이라고 말하지 말 것.**

운영 Vercel 독립 SNS 워커는 수정한 새 브랜치 코드로 READY 배포됐지만 `SOCIAL_PUBLISH_ENABLED=false`로 유지. 기존 3시간 글사진 SNS 예약/발행, 운보다 결제·고객·환불, 운영 사이트는 변경하지 않음.

이미 과거에 생성된 일반 생활팁 release `unboda-shorts-20261029`는 공개 URL을 가진 과거 기록으로는 남아 있으나 **이후 자동 게시 소스로 사용하지 않음**. 새 사주 영상 Release가 없으면 자동 게시 대신 차단해야 함.

또한 지금의 영상을 구성하는 것은 오리지널 **2D 움직이는 그래픽**이지 실제 촬영된 인물 영상이나 3D 실사 모델은 아님. 유료 품질·상업 라이선스, SNS 최종 공개 E2E는 별도 검증 필요.
