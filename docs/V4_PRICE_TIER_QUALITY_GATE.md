# V4 Price-Tier Quality Gate

This branch adds a build-time static release gate for the 54-product paid V4 catalog.

The gate checks that the approved Launch V1 price families remain intact and that higher-priced products own materially stronger analysis responsibilities rather than merely producing longer text.

Checked dimensions include product specialization, distinct evidence responsibilities, action ownership, sibling boundaries, effective safety boundaries, long-range period architecture, timeline uniqueness, review artifacts, and lifetime cross-phase synthesis.

Expected Launch V1 distribution:

- CORE: 41
- DEEP: 8
- LONG_RANGE: 4
- SIGNATURE: 1

The relationship engine already contains a shared decision-safety rule that instructs the model to compare conditions instead of forcing a single relationship choice. The DEEP safety gate therefore counts that runtime rule together with product-specific prohibited claims instead of duplicating the same rule in one product contract.

This change does not enable V4 runtime, change prices, alter payment/database behavior, or make OpenAI calls during the new price-tier audit.
