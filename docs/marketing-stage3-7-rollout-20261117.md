## 3단계 — SNS 콘텐츠 전략 개선
1. 신규 원본 영상은 직장/관계/재물/자기이해 4개 서로 다른 상황으로 시작한다.
2. 둘째 장면에서 개인의 출생 정보를 바탕으로 사주를 참고해 볼 이유를 설명하고, 셋째 장면에서 실제 생활의 작은 점검 방법을 제시한다.
3. 마지막 장면의 운보다 무료 사주 CTA를 카테고리별로 다르게 표현한다. 예언·금전 보장이나 전문가 인증은 주장하지 않는다.
4. 4개의 다른 모티프/첫 화면/상황, 한국어 음성·ASR, 프로모션 15% 이하, 90일 중복 검수 등 기존 독립 검수는 그대로 통과해야 한다.
5. 실제 업로드와 인스타그램 경고·URL·조회는 Metricool에서 각각 확인한다. 릴리스와 실제 공개를 혼동하지 않는다.
6. 성과는 '조회수'만이 아니라 광고·기존 고객 제외 SNS 유입 세션→무료 분석 완료→결과 열람으로 평가한다.

## 4단계 — 무료 사주 사용자 경로
- 현행 출생정보 입력, 출생시간 미상/음력/윤달/만 14세 자기확인 정책을 변경하지 않는다.
- 분석 실패 후 조용한 홈/입력 화면 복귀 대신 개인 정보를 URL에 넣지 않은 실패 플래그와 재입력 안내를 제공한다.
- 모바일 실사용 테스트는 11/18 신규 게시 후: SNS 링크/프로필 → /guest-saju → 입력/분석 → 결과. 결과 화면·오류/재시도·유효 세션, 구매/AI 상담 영향 없음까지 확인 전 완료 처리 금지.
- 분석 중 이벤트와 분석 성공 서버 이벤트는 구별; API 클라이언트가 임의로 성공 이벤트를 생성하지 못한다.
