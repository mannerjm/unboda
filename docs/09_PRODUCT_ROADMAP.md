# 4. 공통 개발 절차

각 상품은 아래 순서로 개발한다.

```text
문서 기준 확인
→ Product Metadata
→ Product Plugin
→ Prompt 규칙
→ Output Schema
→ Parser
→ Validator
→ Self Review
→ UI
→ 실제 AI 테스트
→ 회귀 테스트
→ Git 저장

한 번에 여러 상품을 동시에 고도화하지 않는다.

한 상품을 실제 출력까지 완성한 뒤 다음 상품으로 넘어간다.
